# Сәлем, досым! — образовательная платформа с гонкой

Ученики заходят по имени и коду комнаты (без аккаунтов), решают задания в своём темпе, и их зверята бегут по дорожкам в реальном времени. Учитель создаёт наборы заданий, проводит игру, видит всё на проекторе и скачивает итоги в Excel. Интерфейс на казахском и русском.

## Как опубликовать (≈15 минут, всё бесплатно)

Понадобятся три бесплатных аккаунта: **GitHub** (хранит код), **Neon** (база данных), **Render** (запускает сайт).

1. **GitHub.** Зарегистрируйтесь на github.com → «New repository» → имя, например `salem-dosym` → «Create». На странице репозитория нажмите «uploading an existing file» и перетащите **все файлы и папки из архива** (папку `node_modules` загружать не нужно, её в архиве нет) → «Commit changes».
2. **База данных Neon.** Зарегистрируйтесь на neon.com → создайте проект (регион: Frankfurt) → нажмите «Connect» и скопируйте строку подключения вида `postgresql://…`. Это ваш `DATABASE_URL`.
3. **Render.** Зарегистрируйтесь на render.com через GitHub → «New» → «Blueprint» → выберите репозиторий `salem-dosym`. Render прочитает файл `render.yaml` и попросит две настройки:
   - `DATABASE_URL` — строка из шага 2;
   - `TEACHER_SIGNUP_CODE` — придумайте секретное слово. Без него никто, кроме вас и ваших коллег, не сможет зарегистрироваться учителем.
   Нажмите «Apply». Через 2–4 минуты появится адрес вида `https://salem-dosym.onrender.com` — это публичная ссылка на сайт.
4. Откройте `https://…onrender.com/teacher`, зарегистрируйтесь (логин, пароль и секретное слово) и создайте первый набор заданий.

Если позже подключите свой домен, добавьте в Render переменную `PUBLIC_URL=https://ваш-домен` — тогда ссылка и QR-код в комнате будут с этим адресом.

### Важно про бесплатный тариф Render
- Сайт «засыпает», если к нему 15 минут никто не обращался. Первое открытие после сна занимает до минуты. **Откройте сайт за пару минут до урока** — дальше он работает без задержек.
- На бесплатном тарифе соединения иногда переподключаются. Платформа к этому готова: ученик ничего не теряет, прогресс восстанавливается автоматически.
- Для ежедневных уроков надёжнее тариф Render Starter (около $7 в месяц): он не засыпает.

## Как это устроено

| Часть | Что делает |
|---|---|
| `server/index.js` | HTTP API, WebSocket (Socket.IO), раздача сайта, QR-коды |
| `server/game.js` | Комнаты и гонка: прогресс, таймеры, пауза, места, автосохранение |
| `server/quiz.js` | Проверка наборов и **проверка ответов на сервере** (правильные ответы ученикам не отправляются) |
| `server/auth.js` | Вход учителя: пароль с солью (scrypt), сессия в httpOnly-cookie, ограничение попыток |
| `server/db.js` | PostgreSQL (если задан `DATABASE_URL`), иначе локальный файл SQLite |
| `server/excel.js` | Итоги в .xlsx: таблица результатов и лист с ответами по каждому заданию |
| `public/` | Сайт: приветствие с кошечкой, вход, комната ожидания, гонка, итоги, кабинет учителя |

Защита и надёжность:
- ответ засчитывается только для текущего задания ученика, поэтому повторно начислить баллы невозможно;
- после ошибки действует пауза 1,2 сек (нельзя перебирать варианты очень быстро);
- каждая комната независима, управлять ею может только создавший её учитель;
- состояние игры сохраняется в базу, поэтому обновление страницы, потеря сети и даже перезапуск сервера не сбрасывают прогресс;
- рисунки проверяются по содержимому файла, принимаются только PNG, JPEG, GIF и WebP.

Масштаб: один сервер спокойно держит 100+ учеников в комнате (в тесте 100 учеников, ответ обрабатывается за 1–2 мс). Для нескольких серверов одновременно понадобится Redis-адаптер Socket.IO.

## Запуск на своём компьютере

```bash
npm install
npm start          # http://localhost:3000, база в data/platform.db
npm run test:load  # нагрузочный тест: 100 учеников (сервер должен быть запущен на :4100 или задайте BASE)
```

Переменные окружения: `PORT`, `DATABASE_URL`, `TEACHER_SIGNUP_CODE`, `PUBLIC_URL`, `SQLITE_FILE`.
